# Uzofin Website

## Prerequisites

- Node.js `^22.22.3`, `^24.15.0`, or `>=26.0.0`
- npm `11.19.0`

## Setup

```bash
npm install
```

## Run

To start the local development server, run:

```bash
ng serve
```

Once the server is running, open [http://localhost:4200/](http://localhost:4200/). The app reloads when you change a source file.
